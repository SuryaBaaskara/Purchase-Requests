# Purchase Request

Frontend implementation of a Purchase Request application for outlet branches to order operational products from Head Office.

## Tech Stack

- Next.js
- React
- JavaScript
- Tailwind CSS

## Features

- Product catalog
- Search and category filter
- Product quantity management
- Stock validation
- Add and remove products from cart
- Automatic subtotal and total calculation
- Payment method selection
- Empty cart state
- Submit order loading state
- Responsive design

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/purchase-request-technical-test.git
cd purchase-request-technical-test
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## How to Use

1. Browse products from the catalog.
2. Search or filter products by category.
3. Set the desired quantity.
4. Click **Tambah** to add a product to the cart.
5. Review and adjust products in the cart.
6. Select a payment method.
7. Click **Submit Order / Bayar** to submit the order.
